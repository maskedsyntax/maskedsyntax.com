# Image generation prompt

Mode: built-in image generation

Use case: logo-brand

Asset type: refined brand-mark exploration for favicon, website header, product umbrella brand, and YouTube avatar

Primary request: Create one highly reduced abstract symbol for MaskedSyntax based on concealment and modular product launches, without depicting a mask or using programming punctuation.

Subject: three interlocking rectangular ribbons or app-card fragments arranged so one segment visibly passes behind another; the hidden/revealed overlap creates a subtle S-shaped path in negative space. The whole silhouette should hint at an M only after a second look. It should communicate one parent identity spawning multiple focused products.

Style/medium: premium flat vector identity, rigorous grid, contemporary editorial software-studio aesthetic, bold simple geometry, one memorable optical trick, no decorative detail.

Composition/framing: exactly one centered compact symbol on a square warm-white canvas with generous padding; slightly horizontal or square; readable at 20 px; balanced asymmetry.

Color palette: ink black `#0B0C10` with one electric cobalt `#3B5BFF` segment; must work in pure one-color reproduction.

Scene/backdrop: clean warm-white presentation background.

Constraints: no text, no literal letter M or S drawn plainly, no face, no eyes, no mask silhouette, no code brackets, no `</>`, no slash, no cursor, no shield, no circle container, no cube, no nodes, no gradients, no 3D, no glow, no mockup, no watermark, no thin lines.

Avoid: literal developer iconography and generic hacker-brand tropes.

The generated concept informed the selected woven modular motif. The final production artwork was rebuilt as clean SVG geometry for reliable scaling and theme variants.
